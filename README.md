## Deskripsi Singkat
Permainan Gobblet Gobblers versi papan 5x5 dengan Python & Pygame. Dilengkapi AI berbasis algoritma **Minimax dengan Alpha-Beta Pruning** dan **Bounded Rationality** (kapasitas memori terbatas yang menirukan sifat lupa pemain manusia).

## Cara Menjalankan Game
1. Install dependensi: `pip install pygame`
2. Jalankan GUI interaktif: `python main.py`
3. Jalankan mode terminal: `python main.py --cli`
4. Jalankan seluruh test: `python -m unittest discover tests`
